# Canadian Dietary Reference Intakes (DRI)

Source: Health Canada — Dietary Reference Intakes tables
- Overview: https://www.canada.ca/en/health-canada/services/food-nutrition/healthy-eating/dietary-reference-intakes/tables.html
- Macronutrients: https://www.canada.ca/en/health-canada/services/food-nutrition/healthy-eating/dietary-reference-intakes/tables/reference-values-macronutrients.html
- Vitamins: https://www.canada.ca/en/health-canada/services/food-nutrition/healthy-eating/dietary-reference-intakes/tables/reference-values-vitamins.html
- Elements (minerals): https://www.canada.ca/en/health-canada/services/food-nutrition/healthy-eating/dietary-reference-intakes/tables/reference-values-elements.html
- Interactive calculator: https://health-infobase.canada.ca/nutrition/dietary-reference-intakes-calculator/

These are reference values for normal, apparently healthy individuals eating a typical mixed North American diet. Individuals with specific physiological, health, or lifestyle characteristics may need tailored values.

## Legend / abbreviations

- **EAR** — Estimated Average Requirement: meets the needs of 50% of individuals in a group.
- **RDA** — Recommended Dietary Allowance (bold in source tables): meets the needs of ~97–98% of individuals.
- **AI** — Adequate Intake (used when there isn't enough evidence to set an RDA), marked with `*` in source tables.
- **UL** — Tolerable Upper Intake Level: highest daily intake unlikely to cause adverse effects.
- **CDRR** — Chronic Disease Risk Reduction intake (sodium/potassium): level above which reduction is expected to lower chronic disease risk.
- **ND** — Not determined (insufficient data).
- **RAE** — Retinol Activity Equivalents (vitamin A). **NE** — Niacin Equivalents. **DFE** — Dietary Folate Equivalents.
